**To-Do List Web Application**

A simple and beginner-friendly To-Do List web application built using HTML, CSS, and JavaScript.

----------------------------------------------
🚀 Features
➕ Add new tasks
🔢 Automatically displays tasks with sequential numbers
🧹 Clear all tasks with one click
⌨️ Simple and easy-to-use interface
📱 Clean and responsive design


🛠️ Technologies Used
HTML5
CSS3
JavaScript

⚙️ How It Works
Enter a task in the input box.
Click the ADD button.
The task will be added to the list with a sequence number.
Click CLEAR to remove all tasks.
